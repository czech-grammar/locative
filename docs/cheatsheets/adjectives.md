# Adjective Locative Cheatsheet

All adjective endings at a glance.

---

## Hard Adjectives (nový, starý, dobrý...)

```
┌─────────────────────────────────────────────────────┐
│                 HARD ADJECTIVES                      │
├─────────────────────────────────────────────────────┤
│                                                      │
│   SINGULAR                                           │
│   ─────────                                          │
│   Masculine:  -ý  →  -ém     nový   →  novém        │
│   Neuter:     -é  →  -ém     nové   →  novém        │
│   Feminine:   -á  →  -é      nová   →  nové         │
│                                                      │
│   PLURAL (all genders)                               │
│   ────────────────────                               │
│   -í/-é/-á  →  -ých          noví/é/á →  nových     │
│                                                      │
└─────────────────────────────────────────────────────┘
```

| | Nominative | Locative |
|:--|:-----------|:---------|
| **Masc. Sg.** | nov**ý** | nov**ém** |
| **Neut. Sg.** | nov**é** | nov**ém** |
| **Fem. Sg.** | nov**á** | nov**é** |
| **All Plural** | noví/é/á | nov**ých** |

---

## Soft Adjectives (cizí, jarní, poslední...)

```
┌─────────────────────────────────────────────────────┐
│                 SOFT ADJECTIVES                      │
├─────────────────────────────────────────────────────┤
│                                                      │
│   SINGULAR                                           │
│   ─────────                                          │
│   Masculine:  -í  →  -ím     cizí   →  cizím        │
│   Neuter:     -í  →  -ím     cizí   →  cizím        │
│   Feminine:   -í  →  -í      cizí   →  cizí  (same!)│
│                                                      │
│   PLURAL (all genders)                               │
│   ────────────────────                               │
│   -í  →  -ích               cizí   →  cizích        │
│                                                      │
└─────────────────────────────────────────────────────┘
```

| | Nominative | Locative |
|:--|:-----------|:---------|
| **Masc. Sg.** | ciz**í** | ciz**ím** |
| **Neut. Sg.** | ciz**í** | ciz**ím** |
| **Fem. Sg.** | ciz**í** | ciz**í** |
| **All Plural** | cizí | ciz**ích** |

| | Hard Sg. | Soft Sg. | Hard Pl. | Soft Pl. |

| **Masc.** | -**ém** | -**ím** | -**ých** | -**ích** |
| **Neut.** | -**ém** | -**ím** | -**ých** | -**ích** |
| **Fem.** | -**é** | -**í** | -**ých** | -**ích** |

## Possessive Adjectives

```
┌─────────────────────────────────────────────────────┐
│              POSSESSIVES IN LOCATIVE                 │
├─────────────────────────────────────────────────────┤
│                                                      │
│   můj (my)      →  mém / mé        v mém domě       │
│   tvůj (your)   →  tvém / tvé      v tvém autě      │
│   jeho (his)    →  jeho / jeho     v jeho bytě  ✓   │
│   její (her)    →  jejím / její    v jejím pokoji   │
│   náš (our)     →  našem / naší    v našem městě    │
│   váš (your)    →  vašem / vaší    ve vašem domě    │
│   jejich (their)→  jejich / jejich v jejich domě ✓  │
│                                                      │
│   ✓ = no change (jeho/jejich never change)          │
│                                                      │
└─────────────────────────────────────────────────────┘
```

| Possessive | Masc./Neut. Loc. | Fem. Loc. |
|:-----------|:-----------------|:----------|
| můj | v **mém** | v **mé** |
| tvůj | v **tvém** | v **tvé** |
| jeho | v jeho *(no change)* | v jeho |
| její | v **jejím** | v **její** |
| náš | v **našem** | v **naší** |
| váš | ve **vašem** | ve **vaší** |
| jejich | v jejich *(no change)* | v jejich |

## Demonstratives (This/That)

```
┌─────────────────────────────────────────────────────┐
│            DEMONSTRATIVES IN LOCATIVE                │
├─────────────────────────────────────────────────────┤
│                                                      │
│   ten (that)     Masc./Neut: tom    Fem: té         │
│   ta (that)      Masc./Neut: tom    Fem: té         │
│   to (that)      Masc./Neut: tom    Fem: té         │
│                                                      │
│   Plural (all):  těch                                │
│                                                      │
│   v tom domě     in that house                       │
│   v té knize     in that book                        │
│   v těch městech in those cities                     │
│                                                      │
└─────────────────────────────────────────────────────┘
```

## Interrogatives (Which/What kind)

```
┌─────────────────────────────────────────────────────┐
│            INTERROGATIVES IN LOCATIVE                │
├─────────────────────────────────────────────────────┤
│                                                      │
│   který (which)                                      │
│   ─────────────                                      │
│   Masc./Neut. Sg:  kterém     Ve kterém domě?       │
│   Fem. Sg:         které      Ve které ulici?       │
│   Plural:          kterých    Ve kterých městech?   │
│                                                      │
│   jaký (what kind of)                                │
│   ──────────────────                                 │
│   Masc./Neut. Sg:  jakém      V jakém stavu?        │
│   Fem. Sg:         jaké       V jaké situaci?       │
│   Plural:          jakých     V jakých podmínkách?  │
│                                                      │
└─────────────────────────────────────────────────────┘
```

| | Masc./Neut. Sg. | Fem. Sg. | All Plural |
|:--|:---------------|:---------|:-----------|
| **který** (which) | ve **kterém** | ve **které** | ve **kterých** |
| **jaký** (what kind) | v **jakém** | v **jaké** | v **jakých** |

## Memory Trick

```
┌─────────────────────────────────────────────────────┐
│                  REMEMBER: É vs Í                    │
├─────────────────────────────────────────────────────┤
│                                                      │
│   HARD = É family     │     SOFT = Í family         │
│   ─────────────────   │     ─────────────────       │
│   Sg: -ém, -é         │     Sg: -ím, -í             │
│   Pl: -ých            │     Pl: -ích                │
│                                                      │
│   Hard has "y" (ých)  │     Soft has "i" (ích)      │
│                                                      │
└─────────────────────────────────────────────────────┘
```

## Quick Examples

| Type | Nominative | Locative | English |
|:-----|:-----------|:---------|:--------|
| Hard M | nový dům | v novém domě | in the new house |
| Hard F | stará kniha | o staré knize | about the old book |
| Hard N | velké město | ve velkém městě | in the big city |
| Soft M | cizí člověk | o cizím člověku | about a foreign person |
| Soft F | jarní noc | v jarní noci | on a spring night |
| Poss. | můj pokoj | v mém pokoji | in my room |
| Dem. | ta restaurace | v té restauraci | in that restaurant |
| Inter. | který hotel | ve kterém hotelu | in which hotel |
